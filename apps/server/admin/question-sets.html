Question Sets

Upload YAML

YAML schema reference

Set-level fields

FieldTypeRequiredDescription
namestringYesDisplay name for the question set
authorstringNoAuthor name
descriptionstringNoShort description
defaultTimeLimitnumberNoSeconds per question (default: 10)
tagsstring[]NoSet-level tags
questionsarrayYesList of questions (at least 1)

Question fields

FieldTypeRequiredDescription
idstringNoUnique ID within the set (auto-generated if omitted)
textstringYesThe question text
typestringNomultiple_choice (default) or true_false
categorystringNoTopic category
tagsstring[]NoTags for scoring engine (max 10, auto-lowercased)
timeLimitnumberNoOverride per question (1–120 seconds)
optionsarrayYes2–4 options, each with key (A/B/C/D) and text
correctAnswerstringYesKey of the correct option (A/B/C/D, or true/false)
explanationstringNoShown after answering
mediaobjectNoMedia attachment (see below)
playerDifficultyobjectNoStatic per-player difficulty overrides on a 1–5 scale (1 = easy, 3 = neutral, 5 = hard). Keyed by player name, with optional "default" fallback. Overrides the dynamic tag-based difficulty when set. E.g. {"Alice": 5, "default": 3}

Media fields

FieldTypeRequiredDescription
typestringYesimage, audio, or video
urlstringYesURL of the media file
previewDurationnumberNoSeconds to show before options appear (default: 5)

Example

name: "Example Quiz"
author: "Your Name"
description: "A sample question set"
defaultTimeLimit: 15
tags: [example]

questions:
  - id: ex-1
    text: "What color is the sky on a clear day?"
    category: science
    tags: [science, nature]
    options:
      - key: A
        text: "Red"
      - key: B
        text: "Blue"
      - key: C
        text: "Green"
      - key: D
        text: "Yellow"
    correctAnswer: B

  - id: ex-2
    text: "How many legs does a spider have?"
    tags: [science, animals]
    timeLimit: 10
    options:
      - key: A
        text: "6"
      - key: B
        text: "8"
      - key: C
        text: "10"
      - key: D
        text: "12"
    correctAnswer: B
    explanation: "Spiders are arachnids — they have 8 legs."

  - id: ex-3
    text: "What is the name of this animal?"
    tags: [animals, images]
    media:
      type: image
      url: "https://example.com/cat.jpg"
      previewDuration: 5
    options:
      - key: A
        text: "Dog"
      - key: B
        text: "Cat"
      - key: C
        text: "Bird"
      - key: D
        text: "Fish"
    correctAnswer: B
